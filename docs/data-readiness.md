# Data readiness

Builder does not define vocabulary readiness. A successful build proves only that the selected runtime pack can satisfy that specific request. The checked-in English pack is a 1,000-record development pack suitable for deterministic integration and first-scale generation checks, not general publication. Its current benchmark matrix covers `5×5`, `7×7`, and `9×9` dimensions with fast and balanced strategies, all three difficulty levels, and three seeds per group. See `crosseno/language-en` data-readiness documentation before selecting dimensions, strategy, or quality thresholds.
